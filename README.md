# neoromantic/tap

Homebrew formulae for [ai-usage](https://github.com/neoromantic/ai-usage), which shows how much Claude Code, Codex, and Grok quota is left on every machine a team runs.

```sh
brew install neoromantic/tap/ai-usage
ai-usage
```

Use the full name, `neoromantic/tap/ai-usage`, with `brew install` and `brew upgrade`: Homebrew trusts a formula of a third-party tap by that name, and refreshes the tap before an upgrade only when it is named. What to do after the install, on macOS and Linux, is in the [README](https://github.com/neoromantic/ai-usage#install).

`Formula/ai-usage.rb` is written by the release workflow of ai-usage at each release; do not edit it here.
